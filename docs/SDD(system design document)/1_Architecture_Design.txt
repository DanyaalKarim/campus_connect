# 1. Architecture Design

## 1.1 Overview

CampusConnect uses a three-tier architecture with Flutter frontend 
and Firebase backend. This document serves as the blueprint for 
implementation.

## 1.2 Architecture Pattern

Pattern: Three-Tier + Serverless Backend

Layers:
1. Presentation Layer (Flutter)
2. Business Logic Layer (Firebase)
3. Data Layer (Firestore)

## 1.3 System Architecture

## 1.8 Data Flow Diagrams

### Login Flow
User → Login Screen → AuthService.login() 
    → Firebase Auth → Success
    → AuthProvider → Home Screen

### Event Registration Flow
Student → Events Screen → Event Details 
    → Register Button → FirestoreService.createRegistration()
    → Generate QR → Save to Firestore
    → Show QR Ticket

### Admin Approval Flow
Admin → Dashboard → Pending Events 
    → Approve Button → FirestoreService.approveEvent()
    → Update Status → Notify Organizer
