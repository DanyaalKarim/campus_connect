# 2. Database Design

## 2.1 Overview

CampusConnect uses Cloud Firestore as the primary database. This 
document defines all collections, fields, relationships, and 
indexes needed for implementation.

## 2.2 Database Type

Type: NoSQL Document Database
Provider: Google Cloud Firestore
Structure: Collections > Documents > Fields

Why Firestore:
- Real-time synchronization
- Offline support (cached)
- Auto-scaling
- Free tier sufficient
- Easy Flutter integration

## 2.3 Collections Overview

Total Collections: 8

1. users          - User accounts (all roles)
2. events         - Event information
3. registrations  - Student event registrations
4. announcements  - Official announcements
5. attendance     - Event attendance records
6. feedback       - Student feedback
7. societies      - Society/club information
8. certificates   - Generated certificates

## 2.4 Collection: users

Purpose: Store user account information

Document ID: Firebase Auth UID (auto)

Fields:

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| uid | string | Yes | - | Firebase Auth UID |
| name | string | Yes | - | Full name |
| email | string | Yes | - | Email (unique) |
| role | string | Yes | "student" | student/organizer/admin |
| studentId | string | No | "" | University ID |
| department | string | No | "" | Department |
| profileImage | string | No | "" | Image URL |
| fcmToken | string | No | "" | Push token |
| isActive | boolean | Yes | true | Account status |
| createdAt | timestamp | Yes | now | Creation time |
| updatedAt | timestamp | No | - | Last update |

Example Document:
{
  "uid": "abc123xyz",
  "name": "Ali Khan",
  "email": "ali.khan@university.edu",
  "role": "student",
  "studentId": "CS-2021-045",
  "department": "Computer Science",
  "profileImage": "",
  "fcmToken": "",
  "isActive": true,
  "createdAt": Timestamp,
  "updatedAt": Timestamp
}

Indexes:
- email (ascending, unique)
- role + isActive (composite)

## 2.13 Firestore Security Rules

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    function isSignedIn() {
      return request.auth != null;
    }
    
    function getUserRole() {
      return get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role;
    }
    
    // Users
    match /users/{userId} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && request.auth.uid == userId;
    }
    
    // Events
    match /events/{eventId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn() && 
                    (getUserRole() == 'organizer' || getUserRole() == 'admin');
      allow update, delete: if isSignedIn() && 
                    (getUserRole() == 'admin' || 
                     resource.data.organizerId == request.auth.uid);
    }
    
    // Registrations
    match /registrations/{regId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn();
      allow update: if isSignedIn() && getUserRole() == 'organizer';
    }
    
    // Announcements
    match /announcements/{annId} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && 
                    (getUserRole() == 'organizer' || getUserRole() == 'admin');
    }
    
    // Attendance
    match /attendance/{attId} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && 
                    (getUserRole() == 'organizer' || getUserRole() == 'admin');
    }
    
    // Feedback
    match /feedback/{fbId} {
      allow read: if isSignedIn();
      allow create: if isSignedIn();
    }
    
    // Societies
    match /societies/{socId} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && getUserRole() == 'admin';
    }
    
    // Certificates
    match /certificates/{certId} {
      allow read: if isSignedIn();
      allow write: if isSignedIn() && getUserRole() == 'admin';
    }
  }
}
