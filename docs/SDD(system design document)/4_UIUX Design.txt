# 4. UI/UX Design

## 4.1 Design Philosophy

CampusConnect uses a modern, clean design inspired by:
- Material Design 3 (Google)
- Glassmorphism effects
- Modern SaaS dashboards (2024-2026)
- Professional typography

## 4.2 Color Palette

### Primary Colors
- Primary:        #1976D2  (Indigo Blue)
- Primary Dark:   #0D47A1
- Primary Light:  #BBDEFB
- Gradient:       #1976D2 → #9C27B0

### Status Colors
- Success:        #4CAF50  (Green)
- Warning:        #FF9800  (Orange)
- Error:          #F44336  (Red)
- Info:           #2196F3  (Blue)

### Neutral Colors
- Background:     #F5F7FA  (Light Gray)
- Surface:        #FFFFFF  (White)
- Text Primary:   #1A1A2E  (Dark)
- Text Secondary: #6B7280  (Gray)
- Divider:        #E5E7EB

### Glass Effects
- Glass White:    rgba(255, 255, 255, 0.7)
- Glass Blur:     20px
- Glass Border:   rgba(255, 255, 255, 0.3)

## 4.3 Typography

Font: Poppins (Google Fonts)

| Style | Size | Weight | Line Height |
|-------|------|--------|-------------|
| H1 | 32sp | Bold | 1.2 |
| H2 | 24sp | Bold | 1.3 |
| H3 | 20sp | SemiBold | 1.3 |
| Body Large | 16sp | Regular | 1.5 |
| Body | 14sp | Regular | 1.5 |
| Caption | 12sp | Regular | 1.4 |
| Button | 16sp | SemiBold | 1.2 |

## 4.4 Spacing System

8px grid:
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- xxl: 48px

## 4.5 Border Radius

- Small: 8px (Chips)
- Medium: 12px (Buttons, Inputs)
- Large: 16px (Cards)
- Extra Large: 24px (Modals, Images)

## 4.6 Shadows

Card Shadow:
BoxShadow(
  color: Colors.black.withOpacity(0.08),
  blurRadius: 16,
  offset: Offset(0, 4),
)

Button Shadow:
BoxShadow(
  color: Color(0xFF1976D2).withOpacity(0.3),
  blurRadius: 12,
  offset: Offset(0, 4),
)

Glass Shadow:
BoxShadow(
  color: Colors.black.withOpacity(0.05),
  blurRadius: 20,
  offset: Offset(0, 8),
)

## 4.8 Screen Designs (13 Student Screens)

### Screen 1: Splash Screen
- Gradient background (blue → purple)
- Glass circle with school icon (120px)
- "CampusConnect" white bold (32sp)
- Tagline "University Digital Platform" (16sp)
- Loading indicator at bottom
- Auto-navigate after 2s

### Screen 2: Login Screen
- White background
- Top gradient (blue, 30% opacity, curved bottom)
- Card with:
  - Logo (school icon in blue circle)
  - "Welcome Back" (28sp bold)
  - Email field (glass effect)
  - Password field (with eye toggle)
  - "Forgot Password?" (blue link)
  - "Login" button (gradient, full width, 50px)
- Below: "Don't have account? Sign Up"
- Social login divider
- Google button (white, border)

### Screen 3: Signup Screen
- Similar to login
- Fields: Name, Email, Password, Student ID, Department
- Role selector (Student/Organizer)
- "Sign Up" button (gradient)
- Terms checkbox

### Screen 4: Home Screen
- AppBar: "Hello, Ali!" + Avatar (glass effect)
- Search bar (glass, rounded)
- Banner: Featured event (gradient card)
- Section: "Upcoming Events" (horizontal scroll)
  - Cards (280px width, glass)
  - Poster + Title + Date + Venue
- Section: "Latest Announcements" (vertical)
  - Cards with icon + title + subtitle
- Bottom: 5-tab navigation

### Screen 5: Events Screen
- Search bar (top)
- Category chips (horizontal, colorful)
- Event list (vertical cards):
  - Poster (left, 100x100)
  - Title (bold, 2 lines)
  - Date + Time (with icons)
  - Venue (with icon)
  - Category badge
  - Progress bar (registered/capacity)

### Screen 6: Event Details Screen
- Hero image (poster, 250px)
- Back button (glass circle, top-left)
- Share button (glass circle, top-right)
- Title (24sp bold)
- Category badge
- Info cards (glass):
  - Date with calendar icon
  - Time with clock icon
  - Venue with location icon
- Organizer info (avatar + name)
- Speaker info
- Description (expandable)
- Registration progress bar
- Fixed "Register Now" button (bottom, gradient)

### Screen 7: QR Ticket Screen
- White card (large, rounded)
- Event title (20sp bold)
- Student name + ID
- QR code (250x250, centered)
- Event details
- Status badge

### Screen 8: My Events Screen

### Screen 9: Announcements Screen

  - Category icon (colored circle)

  - Date + Category badge
- Unread indicator (dot)

### Screen 10: Profile Screen
- Gradient header (blue)
- Avatar (80px, white border)
- Name + Email

- Menu list (with icons):

### Screen 11: Certificates Screen

### Screen 12: Feedback Screen

## 4.10 Components

### Custom Button
ElevatedButton with:
- Gradient background
- 16px border radius
- 50px height
- Shadow

### Custom TextField
InputDecoration with:
- Glass background
- 16px border radius
- Prefix icon
- Border radius 16px

### Event Card
Card with:
- Glass background
- 16px border radius
- Image with rounded top
- Padding 16px
- Shadow

### Status Badge
Container with:
- Colored background (20% opacity)
- Rounded corners (8px)
- Small text (12sp)

### Category Chip
FilterChip with:
- Rounded (20px)
- Selected color (primary with 20% opacity)
- Icon + Label

## 4.11 Animations

- Page transition: 300ms slide
- Button ripple: default
- Card hover: 200ms scale 1.02
- Loading: shimmer effect
- Splash: fade in + scale
