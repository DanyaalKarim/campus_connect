## Project Goal

Build a complete university event management platform with:
- Student Android app (Flutter)
- Admin web dashboard (Flutter Web)
- Firebase backend

## Success Criteria

- Working MVP with core features
- Documentation complete
- APK ready for deployment
- Web dashboard live

## Scope (MVP - 9 Day Version)

### Included Features:
- Authentication (Login/Signup)
- Events (Browse, Details, Register)
- QR Ticket generation
- My Events
- Announcements
- Admin: Create/Approve Events

### Excluded Features (Future versions):
- Push Notifications
- Certificates
- Feedback
- Event Photos
- Advanced Analytics

## Daily Commitment

- 10-12 hours per day
