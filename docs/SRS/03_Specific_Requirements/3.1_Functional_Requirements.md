# 3.1 Functional Requirements

## 3.1.1 Overview

This section specifies all functional requirements for the CampusConnect 
platform. Requirements are organized by module and user role. Each 
requirement has a unique ID, description, inputs, process, outputs, 
preconditions, postconditions, exceptions, and priority.

## 3.1.2 Requirement Categories

- FR-A: Authentication
- FR-S: Student Features
- FR-O: Organizer Features
- FR-AD: Admin Features
- FR-SYS: System Features

---

## 3.1.3 Authentication Requirements (FR-A)

### FR-A-01: Student Signup

Description:
The system shall allow a new student to create an account.

Inputs:
- Full name
- Email
- Password
- Student ID
- Department

Process:
1. User opens signup screen
2. User enters required information
3. System validates all fields
4. System creates Firebase Auth account
5. System creates user document in Firestore
6. System redirects to home screen

Outputs:
- User account created
- User document in Firestore
- Success message

Preconditions:
- User not logged in
- Valid email not already registered

Postconditions:
- User can access all student features

Exceptions:
- Email already registered: "Email already in use"
- Invalid email format: "Please enter valid email"
- Weak password: "Password must be 6+ characters"

Priority: High
Module: Authentication

---
