# Appendix B: Analysis Models

## B.1 Overview

This appendix presents the analysis models for CampusConnect, including 
system context diagram, use case diagram, class diagram, sequence 
diagrams, activity diagram, entity-relationship diagram, state diagram, 
data flow diagram, and component diagram.

## B.2 System Context Diagram

The System Context Diagram shows CampusConnect and its interactions with 
external entities including users and backend services.

Diagram Location: diagrams/diagram_01_system_context.png

Description:
- Central system: CampusConnect
- External actors: Student, Organizer, Admin
- Backend services: Firebase, Google Cloud

## B.3 Use Case Diagram

The Use Case Diagram shows all actors and their interactions with the system.

Diagram Location: diagrams/diagram_02_use_case.png

Actors and Use Cases:
- Student: 11 use cases (signup, login, browse, register, etc.)
- Organizer: 6 use cases (create event, scan QR, etc.)
- Admin: 5 use cases (approve, reject, manage users, etc.)

## B.4 Class Diagram

The Class Diagram shows the main classes, their attributes, methods, and 
relationships.

Diagram Location: diagrams/diagram_03_class.png

Main Classes:
- User (abstract base class)
- Student, Organizer, Admin (extends User)
- Event
- Registration
- Attendance
- Feedback
- Certificate

## B.7 Activity Diagram: Event Lifecycle

Shows the complete lifecycle of an event from creation to completion.

Diagram Location: diagrams/diagram_06_activity_lifecycle.png
