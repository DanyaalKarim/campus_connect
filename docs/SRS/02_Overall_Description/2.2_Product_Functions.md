# 2.2 Product Functions

## 2.2.1 Overview

CampusConnect provides three main sets of functions corresponding to the three user roles: Student functions, Organizer functions, and Admin functions. Additionally, the system provides common functions like authentication and notifications.

## 2.2.2 Summary of Major Functions

### A. Authentication and User Management

| Function | Description |
|----------|-------------|
| Signup | User registration with email/password |
| Login | User authentication |
| Logout | Session termination |
| Password Reset | Forgot password functionality |
| Profile Management | View and edit user profile |
| Role Management | Assign roles (student, organizer, admin) |

### B. Student Functions (Android App)

| Function | Description |
|----------|-------------|
| View Home | See upcoming events, announcements, featured events |
| Browse Events | View all approved events |
| Search Events | Search by keyword |
| Filter Events | Filter by category |
| View Event Details | Full event information |
| Register for Event | Enroll in an event |
| View QR Ticket | Get digital ticket with QR code |
| View My Events | See registered events (upcoming/completed) |
| View Announcements | See official announcements |
| Receive Notifications | Get push notifications |
| View Certificates | Access event certificates |
| View Event Photos | See photos from past events |
| Submit Feedback | Rate and review events |

### C. Organizer Functions (Web Dashboard)

| Function | Description |
|----------|-------------|
| Create Event | Add new events with details |
| Edit Event | Modify existing events |
| Delete Event | Remove events |
| Upload Poster | Add event poster images |
| Manage Registrations | View and manage event registrations |
| Send Announcements | Broadcast event-related announcements |
| Scan QR Codes | Mark attendance via QR scanning |
| Upload Event Photos | Add photos after event |
| View Statistics | See event performance metrics |
| View Feedback | Read student feedback |

### D. Admin Functions (Web Dashboard)

| Function | Description |
|----------|-------------|
| Approve Events | Approve pending events |
| Reject Events | Reject with reason |
| Manage Societies | Add, approve, disable societies |
| Manage Organizers | Add, edit, disable organizers |
| Manage Students | View, disable student accounts |
| Send Announcements | Broadcast to all users |
| Content Moderation | Review flagged content |
| View Reports | Platform-wide statistics |
| Platform Settings | Configure system settings |

### E. System Functions (Backend)

| Function | Description |
|----------|-------------|
| Authentication | Firebase Auth |
| Data Storage | Cloud Firestore |
| File Storage | Firebase Storage |
| Push Notifications | Firebase Cloud Messaging |
| Security Rules | Role-based access control |
| Data Backup | Firestore auto-backup |

## 2.2.3 User Interaction Flow

### Student Flow

Open App -> Splash -> Login -> Home
Home -> Events / Announcements / My Events
Events -> Event Details -> Register -> Ticket

### Organizer Flow

Login -> Dashboard -> Create Event -> Submit for Approval
Dashboard -> Manage Events -> Scan QR -> View Stats

### Admin Flow

Login -> Dashboard -> Pending Events -> Approve/Reject
Dashboard -> Manage Users -> Reports -> Announcements
