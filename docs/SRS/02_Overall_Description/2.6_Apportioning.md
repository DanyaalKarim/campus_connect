# 2.6 Apportioning of Requirements

modules, releases, and phases of the project. It helps prioritize work and 
manage the project timeline.

## 2.6.9 Apportioning Guidelines

1. Each requirement must be assigned to at least one module
2. Each requirement must have a priority level
3. Each requirement must be assigned to a sprint
4. Cross-module requirements need coordination
5. Critical path requirements should be in early sprints

## 2.6.10 Review Process

Apportioning will be reviewed:
- At start of each sprint
- If scope changes
- If timeline changes
- At sprint retrospective
