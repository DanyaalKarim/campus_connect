# 5.2 Data Dictionary

## 5.2.1 Overview

This data dictionary provides detailed definitions of all data elements used in the CampusConnect system. Each entry includes the field name, data type, format, constraints, and examples.

## 5.2.2 Field Types Reference

| Type | Description | Example |
|------|-------------|---------|
| string | Text data | "Ali Khan" |
| number | Numeric (int/float) | 100, 4.5 |
| boolean | True/False | true |
| timestamp | Date and time | 2026-10-09T10:30:00Z |
| array | List of items | ["a", "b"] |
| map | Key-value object | {"key": "value"} |
| reference | Firestore document ref | /users/abc123 |

## 5.2.3 User Fields

### uid
- Type: string
- Format: 28-character Firebase UID
- Required: Yes
- Unique: Yes
- Example: "aBcDeFgHiJkLmNoPqRsTuVwXyZ12"
- Notes: Auto-generated by Firebase Auth

### name
- Type: string
- Length: 2-100 characters
- Required: Yes
- Example: "Ali Khan"
- Validation: Letters, spaces, hyphens only

### email
- Type: string
- Format: Valid email address
- Required: Yes
- Unique: Yes
- Example: "ali.khan@university.edu"
- Validation: RFC 5322 email format

### role
- Type: string (enum)
- Required: Yes
- Values: "student", "organizer", "admin"
- Default: "student"
- Example: "student"

### studentId
- Type: string
- Format: Department-Year-Number
- Required: No (only for students)
- Example: "CS-2021-045"
- Validation: Must match university format

### department
- Type: string
- Length: 2-50 characters
- Required: No
- Example: "Computer Science"

### profileImage
- Type: string (URL)
- Format: HTTPS URL
- Required: No
- Example: "https://firebasestorage.googleapis.com/..."

### fcmToken
- Type: string
- Required: No
- Example: "fMEqX...xyz"
- Notes: Updated on each login

### isActive
- Type: boolean
- Required: Yes
- Default: true
- Example: true

### createdAt
- Type: timestamp
- Required: Yes
- Format: ISO 8601
- Example: "2026-10-09T10:30:00Z"
- Notes: Set automatically

## 5.2.4 Event Fields

### eventId
- Type: string
- Format: Auto-generated
- Required: Yes
- Unique: Yes
- Example: "evt_abc123xyz"

### title
- Type: string
- Length: 5-100 characters
- Required: Yes
- Example: "AI & Future Technology Seminar"

### description
- Type: string
- Length: 20-2000 characters
- Required: Yes
- Example: "Join us for an insightful session..."

### category
- Type: string (enum)
- Required: Yes
- Values: "Seminars", "Workshops", "Competitions", "Sports", "Career", "Academic", "Society", "Cultural", "Other"
- Example: "Seminars"

### date
- Type: timestamp
- Required: Yes
- Format: ISO 8601
- Validation: Must be future date
- Example: "2026-11-15T00:00:00Z"

### time
- Type: string
- Format: HH:MM AM/PM
- Required: Yes
- Example: "10:00 AM"

### venue
- Type: string
- Length: 3-100 characters
- Required: Yes
- Example: "Main Auditorium"

### capacity
- Type: number
- Range: 1-10000
- Required: Yes
- Example: 100

### registeredCount
- Type: number
- Range: 0 to capacity
- Required: Yes
- Default: 0
- Example: 78

### organizerId
- Type: string (reference)
- Format: User UID
- Required: Yes
- Example: "aBcDeFgHiJ..."

### organizerName
- Type: string
- Required: Yes
- Example: "Computer Science Department"

### posterUrl
- Type: string (URL)
- Required: No
- Example: "https://firebasestorage.googleapis.com/.../poster.jpg"
- Validation: JPG/PNG, max 5 MB

### speaker
- Type: string
- Length: 0-200 characters
- Required: No
- Example: "Dr. Ahmed Khan, AI Expert"

### registrationDeadline
- Type: timestamp
- Required: Yes
- Validation: Must be before event date
- Example: "2026-11-14T23:59:59Z"

### status
- Type: string (enum)
- Required: Yes
- Values: "pending", "approved", "rejected", "completed"
- Default: "pending"
- Example: "approved"

### rejectionReason
- Type: string
- Length: 0-500 characters
- Required: No (only if rejected)
- Example: "Incomplete description"

### approvedBy
- Type: string (reference)
- Required: No (only if approved)
- Example: "admin_uid_xyz"

### approvedAt
- Type: timestamp
- Required: No
- Example: "2026-10-10T14:20:00Z"

## 5.2.11 Validation Rules Summary

| Field | Rule |
|-------|------|
| email | Valid email format, unique |
| password | Min 6 characters |
| title | 5-100 characters |
| description | 20-2000 characters |
| date | Must be future |
| capacity | 1-10000 |
| registrationDeadline | Before event date |
| rating | 1-5 |
| comment | Max 500 characters |
| qrCode | Unique, starts with "CC-" |
| certificateNumber | Unique, formatted |
