# 1.6 Intended Audience

## 1.6.1 Purpose

This section identifies the intended readers of this Software Requirements 
Specification (SRS) document and describes how each audience should use 
the information contained in this document.

## 1.6.4 Reader Assumptions

This document assumes the reader has:

### General Knowledge:
- Basic understanding of software development
- Familiarity with mobile and web applications
- Understanding of the university environment

### Technical Knowledge:
- For developers: Flutter, Dart, Firebase
- For testers: Software testing fundamentals
- For supervisors: Software engineering principles
- For admin: Basic IT concepts

### Domain Knowledge:
- Understanding of university events
- Familiarity with event registration processes
- Knowledge of student societies
