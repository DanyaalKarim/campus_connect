# 1.2 Scope

## 1.2.1 Product Scope

CampusConnect is a comprehensive university digital platform consisting of 
three integrated components:

### Component 1: Student Mobile Application (Android)
- Platform: Flutter (Dart)
- Target Users: University students
- Purpose: Browse events, register, view announcements, access tickets, 
  view certificates

### Component 2: Organizer Web Dashboard
- Platform: Flutter Web
- Target Users: Society members and department organizers
- Purpose: Create and manage events, scan QR codes for attendance, 
  send announcements, view statistics

### Component 3: Admin Web Dashboard
- Platform: Flutter Web
- Target Users: University administrators
- Purpose: Approve events, manage users and societies, send 
  university-wide announcements, view reports

### Backend: Firebase
- Authentication: Firebase Auth
- Database: Cloud Firestore
- Storage: Firebase Storage
- Notifications: Firebase Cloud Messaging

The following features are **included** in the CampusConnect project:

- ✅ Digital QR ticket generation

- ✅ Event attendance history
- ✅ Certificate viewing
- ✅ Event photos viewing
- ✅ Feedback submission
- ✅ Push notifications
- ✅ Profile management

### Organizer Dashboard Features:
- ✅ Organizer authentication
- ✅ Event creation and editing
- ✅ Event poster upload
- ✅ Registration management
- ✅ Announcement sending
- ✅ QR code scanning for attendance
- ✅ Event photo upload
- ✅ Statistics and feedback viewing

### Admin Dashboard Features:
- ✅ Admin authentication
- ✅ Event approval/rejection
- ✅ Society management
- ✅ Organizer management
- ✅ Student management
- ✅ University-wide announcements
- ✅ Content moderation

## 1.2.3 Out of Scope

The following features are **NOT included** in the current version (v1.0):

### Excluded Platform Features:
- ❌ iOS mobile application (Mac hardware not available)
- ❌ Desktop applications (Windows, macOS, Linux)
- ❌ Web app for students (only mobile)
- ❌ Multi-language support (only English in v1.0)

### Excluded Functional Features:
- ❌ Payment system (events are free)
- ❌ Chat/messaging between users
- ❌ Video streaming
- ❌ Live event streaming
- ❌ Social features (likes, comments, shares)
- ❌ Advanced analytics dashboard
- ❌ AI-based event recommendations
- ❌ Calendar integration (Google Calendar, etc.)
- ❌ Email notifications (only push)

### Excluded Administrative Features:
- ❌ Bulk user import
- ❌ Custom university branding
- ❌ Advanced role management
- ❌ Audit logs
- ❌ API for external systems

## 1.2.5 Scope Constraints

The project must be completed within the following constraints:

| Constraint | Limit |
|------------|-------|
| Timeline | 4 months (1 semester) |
| Team Size | 1-2 developers |
| Budget | Free tier only (Firebase Spark Plan) |
| Platforms | Android + Web only |
| Language | English only |

## 1.2.6 Scope Change Management

Any changes to the scope must be:

1. Documented in a Change Request Form
2. Approved by the Project Supervisor
3. Evaluated for impact on timeline and resources
4. Reflected in updated versions of this SRS
