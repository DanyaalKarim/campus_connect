# 1.3 Definitions, Acronyms, and Abbreviations

## 1.3.1 Definitions

| Term | Definition |
|------|------------|
| **CampusConnect** | The university digital communication and event management platform described in this document |
| **Student** | A registered user of the CampusConnect mobile application enrolled in the university |
| **Organizer** | A user (society member or department representative) who creates and manages events |
| **Admin** | A university administrator who oversees the platform |
| **Society** | A student organization (e.g., IEEE, ACM, sports club) |
| **Event** | Any university activity such as seminar, workshop, competition, or sports gala |
| **Registration** | The act of a student signing up for an event |
| **Attendance** | The confirmation that a student was present at an event |
| **QR Code** | A machine-readable code used for digital tickets and attendance |
| **Ticket** | A digital pass (with QR code) issued to a student after registration |
| **Certificate** | A digital document awarded to students who attended an event |
| **Announcement** | An official message from the university, department, or society |
| **Feedback** | A rating and comment submitted by a student after attending an event |
| **Firestore** | Google's NoSQL cloud database used for data storage |
| **Firebase** | Google's mobile and web application development platform |
| **FCM** | Firebase Cloud Messaging (push notification service) |

## 1.3.4 Terminology Conventions

- **"Shall"** indicates a mandatory requirement
- **"Should"** indicates a recommended requirement
- **"May"** indicates an optional requirement
- **"Must"** indicates a critical requirement
- **"User"** refers to any of the three roles (student, organizer, admin)
- **"System"** refers to the CampusConnect platform
