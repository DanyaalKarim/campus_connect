# 1.2 Scope

## 1.2.1 Product Scope

CampusConnect is a comprehensive university digital platform consisting of 
three integrated components:

### Component 1: Student Mobile Application (Android)
- **Platform**: Flutter (Dart)
- **Target Users**: University students
- **Purpose**: Browse events, register, view announcements, access tickets, view certificates

### Component 2: Organizer Web Dashboard
- **Platform**: Flutter Web
- **Target Users**: Society members and department organizers
- **Purpose**: Create and manage events, scan QR codes, send announcements, view statistics

### Component 3: Admin Web Dashboard
- **Platform**: Flutter Web
- **Target Users**: University administrators
- **Purpose**: Approve events, manage users, send university-wide announcements, view reports

### Backend: Firebase
- **Authentication**: Firebase Auth
- **Database**: Cloud Firestore
- **Storage**: Firebase Storage
- **Notifications**: Firebase Cloud Messaging

## 1.2.2 In Scope

The following features are **included** in the CampusConnect project:

### Student App Features:
- User registration and login
- Home screen (upcoming events, announcements, featured events)
- Event browsing with categories
- Event search
- Event details with full information
- Event registration
- Digital QR ticket generation
- My Events (upcoming and completed)
- Event attendance history
- Certificate viewing
- Event photos viewing
- Feedback submission
- Push notifications
- Profile management

### Organizer Dashboard Features:
- Organizer authentication
- Event creation and editing
- Event poster upload
- Registration management
- Announcement sending
- QR code scanning for attendance
- Event photo upload
- Statistics viewing
- Feedback viewing

### Admin Dashboard Features:
- Admin authentication
- Event approval/rejection
- Society management
- Organizer management
- Student management
- University-wide announcements
- Content moderation
- Reports and statistics
- Platform management

### Backend Features:
- Firebase Authentication (Email/Password)
- Cloud Firestore database
- Firebase Storage for files
- Firebase Cloud Messaging
- Role-based security rules
- Offline data caching

## 1.2.3 Out of Scope

The following features are **NOT included** in version 1.0:

### Excluded Platform Features:
- iOS mobile application
- Desktop applications
- Web app for students (only mobile)
- Multi-language support (English only in v1.0)

### Excluded Functional Features:
- Payment system
- Chat/messaging
- Video streaming
- Live event streaming
- Social features (likes, comments)
- Advanced analytics
- AI recommendations
- Calendar integration
- Email notifications (only push)

### Excluded Administrative Features:
- Bulk user import
- Custom branding
- Advanced role management
- Audit logs
- External API

## 1.2.5 Scope Constraints

| Constraint | Limit |
|------------|-------|
| Timeline | 4 months |
| Team Size | 1-2 developers |
| Budget | Free tier (Firebase Spark Plan) |
| Platforms | Android + Web only |
| Language | English only |

## 1.2.6 Scope Change Management

Any scope changes must be:
1. Documented in Change Request Form
2. Approved by Project Supervisor
3. Evaluated for impact on timeline
4. Reflected in updated SRS version
