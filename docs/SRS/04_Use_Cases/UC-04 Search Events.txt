# UC-04: Search Events

## Use Case Information

| Field | Value |
|-------|-------|
| Use Case ID | UC-04 |
| Use Case Name | Search Events |
| Actor | Student |
| Priority | Medium |
| Complexity | Low |

## Description

A student searches for events by keyword to find specific events of interest quickly.

## Preconditions

1. Student is logged in
2. Student is on Events screen
3. At least one event exists

## Postconditions

1. Filtered events displayed based on search query

## Main Flow

1. Student taps search bar
2. Student types keyword
3. System filters events by title and description
4. System displays matching events

## Alternative Flows

### A1: No Results
- At step 3, no matching events
- System shows "No events found"
- Use case ends

### A2: Clear Search
- Student taps clear icon
- System shows all events again

### A3: Empty Query
- Student clears search bar
- System shows all events

## Exceptions

- E1: Query too short (< 2 characters) - show hint
- E2: Network error - show cached results

## Business Rules

- BR-01: Minimum 2 characters required
- BR-02: Search in title and description
- BR-03: Case insensitive search
- BR-04: Results sorted by relevance

## Non-Functional Requirements

- Search results in < 500 ms
- Debounced input (300ms delay)

## Related Use Cases

- UC-03: Browse Events
- UC-05: View Event Details
